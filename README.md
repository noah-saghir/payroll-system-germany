# Global Payroll & Time-Tracking System

A Python-based command-line application that acts as a flexible payroll system. It accommodates two different contract models: Standard Weekly Contracts and the **German Monthly Salary System**.

## 🚀 Features
- **Flexible Contract Types:** Choose between Weekly/Hourly or Monthly calculation.
- **German Arbeitszeitkonto (Time Bank):** Automatically tracks overtime hours and stores them in a virtual time bank for future time-off, rather than paying them out as immediate cash (simulating real German corporate structures).
- **Performance Bonus System:** Calculates percentage bonuses based on employee evaluation ratings (1-5).
- **Robust Error Handling:** Protected against application crashes using `try/except` blocks for all numerical user inputs.

## 🛠️ Concepts Applied
- Advanced Functions with Multiple Return Values (Tuples).
- Input validation loops (`while True`).
- Exception handling (`try/except`).
